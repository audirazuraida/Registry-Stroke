Data & FHIR Architecture

PRD architecture: SATUSEHAT FHIR API / BigQuery Silver → Gold Table (aggregated) → Tableau dashboard, with daily refresh. The registry uses HL7 FHIR R4 resources such as Patient, Organization, Location, Encounter, EpisodeOfCare, Condition, Observation, Procedure, DiagnosticReport and ImagingStudy.
